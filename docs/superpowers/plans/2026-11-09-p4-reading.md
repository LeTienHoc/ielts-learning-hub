# P4 Reading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete IELTS Academic Reading: filters, multi-passage full tests with band estimates, mobile tabs, highlights, offline buffer, evidence jumps, passage key words → My words, attempt history.

**Architecture:** Extend the P2 engine data model with passages (`practice_set_passages`), a set `kind` and passage key words that reuse P3 `words`. Pure helpers (band, ranges, filters) in lib/feature utils with unit tests; services stay Zod-validated; UI stays in `features/practice` (generic) and `features/reading` (routes, library, history).

**Tech Stack:** Next.js 16 (Cache Components), React 19, TypeScript strict, Supabase + RLS + pgTAP, Zod, Vitest/RTL, Playwright, shadcn/ui.

**Spec:** [docs/superpowers/specs/2026-11-09-p4-reading-design.md](../specs/2026-11-09-p4-reading-design.md)

## Global Constraints

- Branch `feat/p4-reading` from `main`; commit per task; no push/merge unasked. Node 24 on PATH (`export PATH="/c/Users/ADMIN/AppData/Local/nvm/v24.22.2:$PATH"`). No new dependencies.
- Test mode: 20 minutes per one-passage set; **60 minutes** for a full test. A full test has **3 passages and 40 marks**.
- Band only for `kind = "full_test"` with max score 40, labelled "Estimated band" with: "Estimate based on the commonly published IELTS Academic Reading conversion — not an official score." Otherwise "x / y".
- Conversion: 39–40→9, 37–38→8.5, 35–36→8, 33–34→7.5, 30–32→7, 27–29→6.5, 23–26→6, 19–22→5.5, 15–18→5, 13–14→4.5, 10–12→4, 8–9→3.5, 6–7→3, 4–5→2.5, 2–3→2, 1→1, 0→0.
- Filters live in the URL: `/reading?type=<question_type>&level=<A2|B1|B2|C1>`; invalid values are ignored.
- Highlights: device-only, `localStorage` key `ielts-hub:highlights:<attemptId>`; offline answers: `ielts-hub:pending-answers:<attemptId>`; every storage access in try/catch.
- Content `ai_assisted`, published locally only (D-04). No AI tutor, no server-side highlights.
- E2E text assertions on streamed pages scoped to `getByRole("main")` (P3 ruling).

## Review Focus

1. **Selection partly outside the passage or across paragraphs** — highlight clamps to the passage and spans paragraphs; nothing throws. Pinned in Task 5 (`rangeFromSelection` tests).
2. **Overlapping or repeated highlights** — merged, never nested marks. Pinned in Task 3 (`mergeRanges`, `segmentText`).
3. **Blocked or full storage** — highlights and the offline buffer still work in memory for the visit. Pinned in Task 5 (storage-throws tests).
4. **Invalid filter values** (`?type=foo&level=Z9`) — ignored, full library shown. Pinned in Task 3 (`parseReadingFilters`).
5. **Band boundaries and partial sets** — 30→7, 29→6.5, 40→9, 0→0; a 13-mark set shows "x / 13", never a band. Pinned in Task 3 and Task 6.
